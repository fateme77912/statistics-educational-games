# Statistics Educational Games (R Shiny)

این مخزن شامل ۲۳ بازی آموزشی تعاملی برای تدریس و یادگیری مفاهیم آمار و احتمال دوره متوسطه است که با استفاده از فریم‌ورک **R Shiny** طراحی و پیاده‌سازی شده است.

## ساختار پروژه
- `app.R`: صفحه اصلی و پرتال ورود به بازی‌ها
- `games/`: پوشه کدهای مجزای هر بازی (از بازی ۰۰ تا ۲۲)

## نحوه اجرا
برای اجرای هر بازی کافی است فایل `app.R` آن را در محیط **RStudio** باز کرده و گزینه **Run App** را انتخاب نمایید.
